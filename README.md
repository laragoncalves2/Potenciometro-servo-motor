# Potenciometro-servo-motor

Discente: Lara Gonçalves
Docente: Amanda Paul Dull

Prática: Controle de Microservo com Potenciômetro 

https://www.tinkercad.com/things/7Z2uRu2a7MY-controle-de-microservo-com-potenciometro/

Em projetos de IoT, é necessário integrar dispositivos de entrada e saída para realizar ações de controle. Nesta atividade, utilizando o Tinkercad, integrar um potenciômetro e um microservo ao Arduino, utilizando a leitura da entrada para controlar a posição do atuador.
